# Snake Game

A classic Snake game implementation using HTML5 Canvas, CSS, and JavaScript.

## How to Play

1. Open `index.html` in your web browser
2. Click the "Start Game" button to begin
3. Use the arrow keys to control the snake:
   - ↑ (Up Arrow): Move up
   - ↓ (Down Arrow): Move down
   - ← (Left Arrow): Move left
   - → (Right Arrow): Move right
4. Eat the red food to grow and increase your score
5. Avoid hitting the walls or yourself
6. The game speeds up slightly as you eat more food

## Features

- Responsive design
- Score tracking
- Progressive difficulty (game speeds up as you score points)
- Game over detection
- Restart functionality

## Files

- `index.html` - Main HTML structure
- `style.css` - Game styling
- `game.js` - Game logic and functionality
